# FINCTRL — Sistema Web de Controle Financeiro Pessoal

**FINCTRL** é uma aplicação web completa desenvolvida com *PHP, MySQL, HTML, CSS e JavaScript*, criada para auxiliar usuários no gerenciamento de suas finanças pessoais.
A aplicação oferece **cadastro de gastos, dashboard analítico, CRUD completo e autenticação segura**.




## 📖 Sobre o Projeto

O sistema permite registrar despesas, organizar por categorias, calcular o saldo com base no salário e visualizar relatórios mensais através de gráficos e tabelas.


## 🛠️ Tecnologias Utilizadas

### Frontend
- HTML5
- CSS3 
- JavaScript
- Chart.js (para gráficos)

### Backend
- PHP 8+
- MySQL
- Sessões PHP ($_SESSION)

### Ambiente
- XAMPP / WAMP / LAMP
- phpMyAdmin


## 🎯 Funcionalidades

> #### 🔐 Autenticação
> - Login seguro
> - Criptografia de senha com password_hash
> - Controle de acesso por sessão
> - Logout
> - Cadastro de novos usuários
> #### 💸 Gestão Financeira
> - Registrar despesas com:
> - Descrição
> - Valor
> - Categoria
> - Data
> - Cadastro de salário
> - Cálculo automático de: total gasto no mês e saldo disponível
> #### 📊 Dashboard
> - Cards com indicadores principais
> - Gráfico tipo pizza (Chart.js)
> - Tabela com todos os gastos do mês
> - Layout limpo e organizado
>  #### 🗂️ CRUD Completo
> - Criar, visualizar, editar e excluir despesas
> - Gestão de categorias
